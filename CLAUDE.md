# gstack

## Web browsing

- When the Claude in Chrome extension is connected (`mcp__claude-in-chrome__*` tools are available), use it for web browsing — especially for pages that need the user's sign-ins.
- Otherwise use the `/browse` skill from gstack if it is installed, or headless Playwright/Chromium (e.g. in cloud sessions).
