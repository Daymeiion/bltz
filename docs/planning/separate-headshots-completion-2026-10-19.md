# Separate Hero and Bio headshots

## Objective and scope
Give the preview builder Info tab independent image controls for the Hero portrait and Bio / All headshot. Product reference: explicit user request and docs/product/BLTZ_PRODUCT_DOCTRINE.md. Reuse the existing Locker, private preview photo bucket, upload tickets and save controls. No new Media Graph or general media-management workflow.

## Completion report
1. Summary: Info now has separate Hero headshot and Bio headshot panels with previews, existing-photo selectors, HTTPS URL fields and single-image uploads. Bio follows Hero until an override is chosen; Use Hero headshot clears its override. Changing a separate Bio image does not change Hero, and changing Hero preserves an explicit Bio image. Existing Lockers keep their current selected image by default. Bio retains object-fit contain.

## Product direction and review
Strengthens accurate presentation of the athlete's existing identity images across career affiliations and retirement. No new Career, Moment or Value Graph entities; no duplicated third-party workflow or scope drift toward general media management. Reuses the signed private asset infrastructure and one module-level image panel; derives previews without new state/effects, uses labelled native controls, keyboard focus styling and responsive grids. Saved image choices remain authoritative through discovery. No keys, signed URLs or production athlete assets are committed.
