# Article review after career corrections

## Objective and scope
Fix J.J. Arrington's disabled article review checkbox and the shared behavior for future preview Lockers. Product reference: explicit user bug report and docs/product/BLTZ_PRODUCT_DOCTRINE.md. Included: preview builder article review eligibility, explanatory text and duplicate compound-school suggestions. Excluded: production deployment, athlete data edits, server search/scoring changes, queue schema changes and merchandise workflow changes.

Acceptance criteria: correcting school/team/position context for the same athlete permits explicit individual and bulk article review and Add to draft; Save retains the additions; genuine name changes and stale saved versions remain blocked; opening the builder does not append a third compound school when its two constituent schools are already listed.

## Root cause and evidence
The live J.J. editor showed a pending NBC Sports article with both review inputs explicitly disabled, outside any disabled fieldset. The shared guard compared the exact player name, primary school, position, ordered school labels and ordered pro-team labels. Removing a school suggestion invalidated this entire fingerprint, and Save did not rebind it. A separate saved editor showed why the extra row kept returning: the affiliation helper appended the literal combined value California; College of the Canyons even though both schools were already listed. The original editor had two school rows; the fresh editor had three. The fresh editor's individual review input was enabled, while the original editor displayed the identity/stale-state warning.

## Product direction
Strengthens accurate, explicitly reviewed athlete-to-news associations and preserves career reconstruction while affiliations are corrected. Remains useful after an athlete changes teams or retires. No new Career, Moment or Value Graph schemas, no third-party workflow duplication, and no drift toward generalized media management. The existing private preview still does not itself create a canonical Athlete Career ID.
