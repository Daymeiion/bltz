# Getty film row image fit and scrolling - October 18, 2026

## Objective and scope
User request: show the full image in the existing Getty film row, fit each container to its image proportions, and loop slowly on page load with hover/manual-input pauses. Product reference: docs/product/BLTZ_PRODUCT_DOCTRINE.md. Reuse the private-preview Photo Room strip, existing photo inputs, selection callbacks and licensing showcase. No new provider integration, ingestion, rights workflow, data model or route.

## Completion report
1. **Summary:** Thumbnails use object-fit: contain. Loaded natural image ratios set each card's width at the existing desktop/mobile row heights. Portrait controls stack at opposite corners to prevent overlap. Native horizontal scrolling advances at 18 CSS pixels per second, returns to the start after reaching the end, and repeats. Hover pauses immediately; leaving resumes unless another pause applies. Wheel, touch and scrollbar input suspend motion for three seconds after input; focus, dragging and the open licensing modal also suspend motion. A dedicated Pause/Play control provides a persistent opt-out, and reduced-motion preference disables automatic motion. Rows without overflow stay stationary.
